# 4-3 人體心血管系統的組成：課後評量

學生作答網址：https://yrhc1255.github.io/biology-assessment-/

依翰林《115 國中自然 1 上備課用書》第 118～123 頁設計，包含第 121 頁的小魚尾鰭血流觀察活動。共 20 題單選題，每題 5 分，滿分 100 分。

學生填寫班級、座號、姓名後作答，交卷可查看答案、解析與教材頁碼。頁面不設答題索引，可列印題目卷或交卷後的解析。

## 成績上傳

交卷後自動送至 Google Apps Script，伺服器依作答重新計分，寫入教師私人 Google 試算表。「成績」保留每位學生的最新分數、最高分數與作答次數；「作答紀錄」保留每次提交。

成功訊息須收到伺服器確認後才顯示。失敗時可重試，事件識別碼可避免重複登錄。待傳資料只暫存於本分頁，關閉分頁後清除。

## 接收程式

`gas/Code.gs` 與 `gas/appsscript.json` 為對應的 GAS 程式與設定。若自行建立服務，另以 `PrivateConfig.example.txt` 建立私有設定，填入自己的試算表 ID 與管理用隨機字串；私有設定不可提交 Git。需準備名為「成績」與「作答紀錄」的工作表，欄位順序對應程式中的資料列。

公開端點提供狀態與提交回覆，不提供全班成績查詢。試算表維持私人，不在本儲存庫公開其識別碼或連結。教材 PDF、私人設定與學生資料未納入發佈。
